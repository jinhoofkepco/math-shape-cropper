# 수학 문제집 도형 크롭 보조 앱

문제집 사진에서 도형 영역을 대략 드래그하면, Python으로 경계를 조금 보정하고 흑백 대비를 정리해서 저장하는 보조 앱입니다.

## 기능

- 왼쪽: 선택한 폴더 또는 단일 파일의 문제집 사진/PDF 페이지 목록을 세로로 표시
- 가운데: 선택한 문제 페이지 표시 및 드래그 크롭
- 오른쪽: 보정된 크롭 미리보기 목록을 한 줄에 3개씩 표시
- 오른쪽 상단: 공통 이름 입력
- 페이지별 크롭 그룹 위: 페이지 중간 이름 입력
- 페이지 중간 이름 기본값은 빈칸이며, 워크북 ZIP 생성 시 비어 있으면 이전 이름의 마지막 숫자를 1 증가시킴 (`3_5_` -> `3_6_`)
- 각 크롭 아래: 짧은 후속 이름 입력, 기본값은 페이지 안에서 `0`, `1`, `2`, `3`
- 숫자 이름 입력칸 양쪽의 `<`, `>` 버튼으로 값 증감
- 크롭 미리보기 클릭: 해당 크롭 삭제
- 저장 버튼 왼쪽: 저장 폴더명 입력
- 저장 시 이미지 파일명: `페이지번호-페이지내순번.png` 형식으로 전체 저장 (`1-0.png`, `1-1.png`, `1-2.png`)
- 저장 시: 원본 파일과 보정 좌표를 담은 `manifest.json`도 함께 저장
- 모드 선택: `도형 저장`, `워크북 생성`, `fast` 모드 지원
- 워크북 생성 모드: 문제 전체를 드래그하면 왼쪽 위 문제 번호와 빨간 답을 OCR로 읽고, 빨간 답은 이미지에서 삭제
- 워크북 생성 모드: `생성`을 누르면 워크북 앱의 `workbook.json + images/` ZIP 형식으로 내보내기
- `fast` 모드: 직접 놓은 선을 기준으로 여러 문제 영역을 빠르게 생성
- `fast A`: 클릭 위치마다 전체 폭 가로선을 만들고, 위에서 아래 순서로 크롭 생성
- `fast A`로 만든 문제는 ZIP 생성 시 이미지 표시 폭을 항상 최대 폭으로 고정
- `fast A`로 만든 크롭은 2번째 영역을 자동 제외
- `fast B`: 첫 클릭으로 세로 구분선을 만들고, 이후 클릭 위치에 따라 왼쪽/오른쪽 가로선을 만든 뒤 왼쪽 위→아래, 오른쪽 위→아래 순서로 크롭 생성
- `fast` 모드의 선은 만든 뒤 마우스로 드래그해 위치 조정 가능
- `fast` 모드의 `외곽설정`: 드래그로 전체 크롭 외곽을 지정하면 모든 선 크롭이 그 사각형 안에서만 생성
- 지우개 사용 중 `외곽설정`을 누르거나 페이지를 옮기면 지우개가 자동 해제됨
- 영역 지우개는 드래그 시작점의 색으로 선택 영역을 칠함
- `fast` 모드에서 선을 그은 뒤 페이지를 옮기면 현재 페이지의 선 크롭이 자동 생성됨
- 외곽설정은 다음 페이지로 넘어가도 유지되며, 다시 맞추고 싶으면 `외곽설정`을 한 번 더 눌러 새로 드래그
- 워크북 ZIP 생성 시 페이지별 그룹 이름 입력칸을 책의 소단원 이름으로 쓰며, 같은 소단원 이름은 같은 chapter 그룹으로 묶임
- `fast`/워크북 ZIP 안의 `images/` 파일명도 `페이지번호-페이지내순번.png` 형식 사용

## 실행

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run_app.py
```

PDF 파일은 PyMuPDF로 페이지를 렌더링합니다. `python -m pip install -r requirements.txt`를 다시 실행하면 설치됩니다.

워크북 생성 모드의 OCR은 Tesseract OCR 실행 파일이 필요합니다. Windows에서는 `winget install --id UB-Mannheim.TesseractOCR -e`로 설치할 수 있습니다.

특정 이미지 폴더를 바로 열고 싶으면:

```powershell
python run_app.py "C:\문제집사진폴더"
```

## 사용 방법

1. `폴더 선택`으로 문제집 사진/PDF 폴더를 고르거나, `파일 선택`으로 PDF/이미지 파일 하나를 고릅니다.
2. 왼쪽 목록에서 페이지를 선택합니다.
3. 가운데 페이지 화면에서 도형을 대략 드래그합니다.
4. 오른쪽에 보정된 크롭이 추가되면 공통 이름과 개별 이름을 설정합니다.
5. 저장 폴더명을 입력하고 `저장`을 누릅니다.

## 보정 방식

OpenCV 없이도 실행되도록 Pillow와 NumPy만 사용합니다. 저장 범위는 마우스로 드래그한 영역을 기준으로 맞추고, 저장 전 선명도를 보정합니다. 종이 여백과 내부 명암으로 판단되는 밝거나 촘촘한 채움 영역은 PNG alpha 채널로 투명화하고, 진한 테두리와 글자는 line-art 형태로 남깁니다.

## GitHub 관리

현재 프로젝트는 로컬 git 저장소로 관리할 수 있습니다. 새 GitHub 저장소를 만든 뒤 아래처럼 원격을 연결하면 됩니다.

```powershell
git remote add origin https://github.com/사용자명/저장소명.git
git branch -M main
git push -u origin main
```

또는 저장소 URL을 받은 뒤 아래 스크립트를 실행해도 됩니다.

```powershell
.\scripts\publish_to_github.ps1 "https://github.com/사용자명/저장소명.git"
```
